AUTOMATIC PLANT WATERING SYSTEM

A precision irrigation system that continuously monitors soil moisture and intelligently activates a water pump when the plant requires hydration.

01 / OVERVIEW

WATER ONLY
WHEN NEEDED.

The system replaces manual watering with sensor-based decision making. Soil moisture is measured continuously, converted into a percentage, and compared against predefined moisture thresholds.

SYSTEM / 001

The Core Idea

Instead of watering plants according to a fixed schedule, the system responds to the actual condition of the soil. This reduces unnecessary watering and provides a more controlled irrigation process.

CONTROL / 002

Closed-Loop Operation

The moisture sensor provides feedback to the Arduino. The Arduino decides whether the pump should operate, creating a simple closed-loop automatic watering system.

03 / LOGIC

FROM SOIL
TO DECISION.

Every watering decision follows a simple chain: measure → calculate → classify → control.

STEP 01

Measure

The soil moisture sensor continuously produces a raw electrical reading.

STEP 02

Convert

Arduino converts the calibrated sensor reading into a moisture percentage.

STEP 03

Classify

The percentage is compared with the 80% and 95% threshold values.

STEP 04

Control

The Arduino switches the pump through the MOSFET whenever watering is required.
